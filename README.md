# Yamine Bouzembrak — Hybrid Premium portfolio

A responsive, GitHub Pages-ready academic portfolio built with plain HTML, CSS and JavaScript.

## Deploy to GitHub Pages

1. Download and unzip this project.
2. Open the repository that publishes `https://yamine15.github.io`.
3. Replace the existing site files with `index.html`, `styles.css`, and `script.js` (keep a backup first).
4. Commit and push to the publishing branch.
5. In GitHub, open **Settings → Pages** and confirm the source branch/folder is correct.

No build step or package installation is required.

## Before publishing

- Verify the selected publication list and project descriptions against the latest Research@WUR record.
- Add a preferred public email/contact route if you want direct email contact.
- Add an approved professional portrait if desired; the hero currently uses a custom CSS/SVG research visual rather than a stock photo.
- Check all profile URLs and course details.
- The publication section is deliberately a selected list; the Research@WUR link is the authoritative full record.

## Files

- `index.html` — semantic page structure, SEO metadata and content
- `styles.css` — responsive visual system and animations
- `script.js` — mobile navigation, scroll progress, reveal effects and publication filter
