# Yamine Bouzembrak — Premium Website Redesign

A static, responsive website designed for GitHub Pages.

## Files
- `index.html` — page structure and existing supplied academic content
- `styles.css` — premium editorial visual system and responsive layouts
- `script.js` — mobile navigation, reading progress, publication filters and reveal effects
- `assets/yamine-bouzembrak.png` — portrait supplied for this redesign

## Preview locally
Open `index.html` in a browser. For a local server, run:
`python -m http.server 8000`

## Deploy to GitHub Pages
1. Back up the current repository.
2. Replace the existing site files with the contents of this folder.
3. Commit and push to the branch/folder configured in GitHub Pages.
4. Check the deployed site on desktop and mobile.

## Before publishing
- Verify project dates, roles, course details and publication metadata.
- Add DOI or publisher links to individual publications where appropriate.
- Confirm the preferred public biography and contact destination.
- Consider adding a custom domain and a dedicated social-sharing image.
- The Google Fonts import requires an internet connection; system fallbacks are included.

The project and publication text is retained from the HTML supplied for this redesign. No new academic achievements or metrics have been added.


## Readability update
The stylesheet includes a site-wide typography pass: larger body copy, navigation, research descriptions, project summaries, publication metadata, course details and small labels, with mobile-specific sizing and improved text contrast.
